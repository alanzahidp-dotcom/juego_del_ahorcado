# juego_del_ahorcado


#Este proyecto consiste en desarrollar un juego del Ahorcado, en el que el jugador debe descubrir una palabra secreta ingresando diferentes letras.

El proyecto se desarrolla progresivamente, comenzando con conceptos básicos de programación y posteriormente incorporando condicionales y bucles para construir un juego más completo e interactivo.

Objetivo

El objetivo es aprender a desarrollar un programa paso a paso, aplicando diferentes estructuras de Python y comprendiendo cómo se relacionan con un diagrama de flujo.

Conceptos utilizados
Variables
Entrada de datos con input()
Salida de datos con print()
Condicionales if, elif y else
Operadores de comparación
Operadores lógicos
Cadenas de texto
Listas
Ciclo while
Ciclo for
break
continue
Operador in
Funcionamiento

El juego funciona de la siguiente manera:

Se define una palabra secreta.
Se establece una cantidad inicial de intentos.
El jugador ingresa una letra.
El programa comprueba si la letra pertenece a la palabra.
Si la letra es correcta, se registra como acertada.
Si la letra es incorrecta, se resta un intento.
El programa muestra el progreso de la palabra.
El juego continúa mientras queden intentos.
Si el jugador descubre la palabra, gana.
Si se terminan los intentos antes de descubrirla, pierde.
